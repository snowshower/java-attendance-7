# java-attendance-precourse

### input
- 기능 선택
  - 1 출석 확인
  - 2 출석 수정
  - 3 기록 확인
  - 4 제적 확인
  - Q 종료
- 출석 확인
  - 닉네임 입력
  - 등교 시간 입력
- 출석 수정
  - 수정하려는 닉네임 입력
  - 수정하려는 날짜 입력
  - 변경할 시간 입력
- 출석 기록 확인
  - 닉네임 입력

### output
- 시작 문구
- 출석 확인
  - 날짜+시간+출석/지각/결석 여부
- 출석 수정
  - 변경전 출석정보, 변경후 출석정보
- 출석 기록 확인
  - 모든 출석 정보

### util
- 파일 불러와서 크루 세팅

- 지각횟수, 결석횟수 던져주면 제적 여부 반환하는 메소드(경고 or 면담 or 제적)
  - 지각 3회 -> 결석 1회
  - 결석 2회 이상 -> 경고
  - 결석 3회 이상 -> 면담
  - 결석 5회 초과 -> 제적

### 출석/지각/결석 enum
- 출석
- 지각
- 결석
- 기준시간, 출석시간 던져주면 지각인지 결석인지 판단하는 메소드
  - (출석시간 없어도 결석)
  - 5분 초과 -> 지각
  - 30분 초과 -> 결석
  - 출석 기록 x -> 결석

### 출석 정보 하나
- 닉네임(입력)
- 출석날짜 LocalDate(오늘날짜)
- 출석시간 LocalTime(시분)(입력)
- 출석정보 LocalDateTime -> 출석날짜+출석시간으로 생성
- 출석/지각/결석여부 enum -> 출석정보, 요일규칙으로 생성

/*
### 크루
- 닉네임 String
- 출석정보(년월일시분+출석/지각/결석)
- 출석/지각/결석 횟수 리스트
- getter
*/

### 전체 출석부(리포지토리) 하나 만들기
- Map<닉네임, List<출석정보하나>>
- 닉네임에 해당하는 출석 정보 하나 저장
- 닉네임, 날짜로 출석정보하나 불러오기
  - 닉네임에 해당하는 출석정보 먼저 전부 리스트로 반환
  - 반환된 리스트에서 다시 날짜로 찾기
- 닉네임에 해당하는 출석정보리스트 반환하기

### 출석 확인
- 닉네임, 출석시간 입력
- 출석 정보 하나 생성
- 출석부에 저장

### 출석 수정
- 닉네임 입력
- 날짜 입력
- 출석부에서 닉네임과 날짜에 해당하는 출석정보 불러오기
- 시간 입력
- 불러온 출석정보의 시간 변경

### 출석 기록 확인
- 닉네임 입력
- 출석부에서 닉네임에 해당하는 출석정보 전부 가져오기
  - 출석횟수, 지각횟수, 결석횟수 계산
  - 날짜, 시간, 출석/지각/결석, 횟수

### 필요한 기능
1. 닉네임, 시간 입력해서 출석 등록
- 출석/지각/결석인지 판단까지

2. 닉네임, 날짜, 시간 입력해서 출석 수정
- 수정한 정보가 출석/지각/결석인지 판단까지

3. 닉네임 입력해서 해당 크루의 기록 확인
- 출석 기록 전부 + 출석/지각/결석 카운트 + 제적 정보까지

4. 제적 위험자 확인
- 지각,결석 정보가 있는 크루 출력
- 정렬 필요
